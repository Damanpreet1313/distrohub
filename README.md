# DistroHub

DistroHub is a browser-based Linux environment management platform.

It allows users to provision isolated Linux containers and interact
with them through a web-based terminal.

## Planned Features

- Multiple Linux distributions
- Docker-based environment provisioning
- Browser-based terminal
- User authentication
- Persistent workspaces
- Environment lifecycle management
- Resource monitoring

## Technology Stack

- React
- FastAPI
- Docker
- PostgreSQL
- WebSockets
- xterm.js
